# Ana Dépôt — design system

Small on purpose. Tokens live in **one place**: `src/app/globals.css` (`@theme`). Components use semantic
names, never raw hex. Rebranding = editing that block plus `src/config/site.ts`.

## Positioning
Ana Dépôt is a general-merchandise retailer and wholesaler. The hero uses a still life of goods from several categories (furniture, hardware,
bedding, footwear, household) on the teal arch — no single category dominates, and the copy names no specialty. The promo band uses neutral cartons
("one, several, many") for quantity pricing. Sample artwork is generated by `scripts/generate-sample-images.mjs` and replaced by real photos later.

## Direction
Calm, premium-approachable retail. Warm off-white canvas, deep-teal primary, terracotta accent used sparingly
(sale, promotion, key highlights). Product imagery carries the page; UI chrome stays quiet. Restrained radii,
almost no shadows, no decorative gradients. Category-neutral: nothing assumes clothing, electronics, food…

Rules: primary buttons are `brand-700`; `accent` only for discounts/promotions; text on `brand-700`,
`accent-600` is white (both ≥ 4.5:1).

## Typography
Two families: **Fraunces** (display/headings, `font-display`) and **Geist Sans** (everything else).
Utilities (defined in `globals.css`): `text-display` (hero), `text-h1`, `text-h2` (serif, fluid via `clamp`),
`text-h3` (sans 17px/600), `text-body` (16px), `text-label` (14px/500), `text-caption` (13px),
`text-eyebrow` (12px caps), `text-price` (tabular numerals). Form controls are 16px to prevent iOS zoom.

## Spacing, layout, breakpoints
- `container-page`: max 1280px, gutters 16 / 24 / 32px (base / `sm` / `lg`).
- Section rhythm: `mt-14 sm:mt-20` between homepage sections. Grid gaps: `gap-3 sm:gap-5 lg:gap-6`.
- Breakpoints are Tailwind defaults (`sm 640 · md 768 · lg 1024 · xl 1280`). Mobile first; the header
  switches to full navigation + inline search at `lg`.
- Product grid: 2 cols → 3 (`sm`) → 4 (`xl`; 3 when a filter sidebar is present).

## Shape & depth
Controls `rounded-control` (6px), cards `rounded-card` (10px), pills only for chips/search. `shadow-float` only
for layers above the page (toasts, drawers). Borders (`border-line`) separate content, not shadows.

## Components (`src/components/ui`)
- **Button / ButtonLink** — variants `primary|secondary|outline|ghost|accent|danger`, sizes `sm|md|lg`
  (md = 44px touch target), `loading` state.
- **TextField / PasswordField / SelectField / Checkbox** — label, hint, error wired with `aria-describedby`
  and `aria-invalid`. After a failed submit, `focusFirstInvalid()` moves focus to the first bad field.
- **Drawer** — native `<dialog>`; `side="left|right|top|bottom"`. Used for mobile nav, search, filters, forms.
- **Alert / DemoNotice** — feedback and the *mandatory* marker for anything simulated.
- **Badge**, **Breadcrumbs**, **Price** (current / previous / discount, screen-reader labels),
  **QuantityStepper**, **OrderLines**, **TotalsList**, **EmptyState / ErrorState / Skeleton**, **Toast**
  (`useToast()`, polite live region).
- **Price tiers / pricing** (`components/ui/price-tiers.tsx`, `price.tsx`) — "price by quantity" table with the active row highlighted, wholesale tag
  (accent), "add N more to pay X per unit" hint. Always show the unit (`/ pièce`). **SmartImage** falls back to a neutral placeholder.
- **Money** (`MoneyText`, `MoneyTotals`, `MoneyRows`) — amounts always carry their ISO code; with several currencies each gets its own line/row
  ("Total · HTG", "Total · USD"), never a sum. An info `Alert` explains a mixed cart (no exchange rate).
- **ProductCard** (`features/catalog`) — every optional field (compare price, rating, badge, availability) may
  be absent; whole card is one stretched link, the add button sits above it.

## Administration look
Same tokens, denser: `bg-sand-50` canvas with white `rounded-card` panels, 16rem sidebar (drawer below `lg`), sticky 56px top bar
(language, notifications, account). Status colors are fixed per reservation status (`reservationStatusTone`): pending = warning,
accepted = info, ready = success, collected = brand, rejected = danger, cancelled/expired = neutral. Lists are tables on `md+` and
cards below. Destructive actions (reject, cancel, expire) use the `danger` button and always open a confirmation dialog
(`Drawer side="center"`). Customer-visible notes use a green-tinted quote; internal notes a dashed neutral box with an explicit label.

## Administration forms (catalog)
Product form = numbered sections (`Section`) with a sticky step list + live preview on `xl`, and a fixed action bar (save draft / publish, unsaved indicator).
Progressive disclosure: variants and wholesale are opt-in toggles; optional fields say "Facultatif". Errors are inline with `aria-describedby` and
summarised in the final "Vérification" section with anchors. Tables (products, inventory) are horizontal-scroll-safe on phones; image cards stack on narrow screens.

## Internationalization
Language switch = `FR | KR` pill (single compact button on phones). Layouts must survive Haitian Creole being longer than French in
places; never truncate status labels. Don't hardcode text: see `src/i18n`.

## Accessibility baseline
Skip link, one `<h1>` per page, landmarks, visible `:focus-visible` ring, ≥ 44px targets, `aria-live` for toasts
and cart/stepper feedback, `prefers-reduced-motion` respected, search is an ARIA combobox, dialogs are native.
